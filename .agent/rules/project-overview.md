## Project Name

announcing.app

## Concept

A dedicated "SNS-style" broadcasting platform for one-way communication.

- No Likes, No Replies, No Noise.
- Focus on "Announcing" updates to subscribers via Web Push.
- Minimalist design inspired by Bear Blog but with an SNS feed UI.

## Core Value Proposition

- **For Writers:** A calm place to publish updates without worrying about algorithms or engagement metrics. Ideal for businesses (e.g., local shops, SMEs) and anti-SNS individuals.
- **For Readers:** A quiet feed to follow important updates without social noise.

## Key Features

1. **Channels:** Users can create channels.
2. **Subdomains:** Each channel has a unique URL (e.g., `my-shop.announcing.app`).
3. **Posts:** Text-based posts with optional images/links.
4. **Web Push:** Readers can subscribe to channels via browser native push notifications.
5. **Read-Only Interaction:** No social features (likes/comments) to maintain mental peace.

## User Roles

- **Owner:** Creates channels and posts updates.
- **Subscriber:** Subscribes to channels to receive push notifications (Browser-based, no account required for reading).
